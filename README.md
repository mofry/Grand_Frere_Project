# Grand Frère

Grand Frère is a modern school meal card concept designed to simplify and secure student spending in educational environments. The project presents a digital solution where parents can reload a student card, schools can manage meal budgets, and students can access a controlled cashless system without handling physical cash.

This repository contains the first product landing page and prototype for the concept, built with Nuxt.js and Tailwind CSS.

## Why this project matters

Schools and families often face the same challenges:

- cash-based student spending is hard to track
- parents do not always know how much is being spent
- schools need a safer and more transparent way to manage meal budgets
- students need a simpler way to access their meal allowance without friction

Grand Frère addresses these issues by proposing a digital payment experience centered on transparency, control, and security.

## Product vision

Grand Frère is a smart card solution for school cafeterias that allows:

- parents to top up a student meal card securely
- schools to monitor spending in a controlled environment
- students to benefit from a cashless and supervised system
- institutions to reduce misuse and improve financial visibility

The project is positioned as a user-friendly, modern, and trustworthy solution for educational institutions.

## Getting started

### Prerequisites

Make sure you have Node.js installed on your machine.

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```
